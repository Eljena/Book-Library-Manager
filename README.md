# Bücherverwaltungssystem

Eine Webanwendung zur Verwaltung von Büchern mit vollständigen CRUD-Funktionalitäten, entwickelt mit **Spring Boot**.

---

## Features

- Bücher anlegen, anzeigen, bearbeiten und löschen (CRUD)
- Bücher suchen, filtern & sortieren
- Datenbankanbindung zur persistenten Speicherung
- responsive Benutzeroberfläche mit Bootstrap

---

## Tech Stack

| Bereich      | Technologien         |
|--------------|----------------------|
| Backend      | Java, Spring Boot    |
| Datenbank    | MySQL / H2           |
| Frontend     | Thymeleaf, Bootstrap |
| Build-Tool   | Maven                |
 
---

## Über das Projekt

Dieses Projekt entstand während meiner Tätigkeit als Werkstudentin in der Softwareentwicklung. Ziel war die praktische Anwendung von Spring Boot — insbesondere der Schichtenarchitektur (Controller, Service, Repository) sowie der Integration einer relationalen Datenbank mit Spring Data JPA.
