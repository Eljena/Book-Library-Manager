# Bücherverwaltungssystem

Eine Webanwendung zur Verwaltung von Büchern mit vollständigen CRUD-Funktionalitäten, entwickelt mit **Spring Boot**.

---

## Features

- Bücher anlegen, anzeigen, bearbeiten und löschen (CRUD)
- Bücher suchen, filtern & sortieren
- Datenbankanbindung zur persistenten Speicherung
- responsive Benutzeroberfläche mit Bootstrap

---

## Tech Stack

| Bereich      | Technologien         |
|--------------|----------------------|
| Backend      | Java, Spring Boot    |
| Datenbank    | MySQL / H2           |
| Frontend     | Thymeleaf, Bootstrap |
| Build-Tool   | Maven                |
